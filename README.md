# Atividade — Banco de Dados Kart

Projeto desenvolvido em MySQL para praticar modelagem, manipulação e consulta de dados relacionais.

## Organização
- `Atividade_kart 2024 Gustavo.sql`: script principal contendo a criação do banco de dados `kart`, tabelas (`patrocinio`, `equipe`, `piloto`, `temporada`, `etapa`, `etapa_has_piloto`), inserções de dados, atualizações (`UPDATE`) e exclusões (`DELETE`).

## Tecnologias
- MySQL
- MySQL Workbench / DBeaver

## Como abrir
1. Baixe ou clone este repositório.
2. Abra seu gerenciador MySQL (ex: MySQL Workbench).
3. Selecione **File > Open SQL Script** e escolha o arquivo `Atividade_kart 2024 Gustavo.sql`.
4. Execute o script para criar e manipular o banco de dados.
